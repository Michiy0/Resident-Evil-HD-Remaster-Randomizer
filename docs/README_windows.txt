RESIDENT EVIL HD REMASTER RANDOMIZER — Windows
=============================================

You need the game on Steam, up to date. (Français : voir LISEZ-MOI.txt)

INSTALLING (only once)
1. Run Resident Evil HD Remaster Randomizer.exe.
   If Windows shows "Windows protected your PC": click "More info", then "Run anyway"
   (the exe is not signed).
2. Check that the game folder is the right one (otherwise "Browse…").
   If an orange message mentions an "unsupported version", your game is not the current
   Steam version: the randomizer stays inactive.
3. Click "Install the DLL".

PLAYING
1. "Generate a seed" tab: pick your options, then "Generate seed"
   (leave "Install the seed in the game" ticked).
2. Start the game from Steam: NEW GAME with CHRIS, on EASY difficulty.
   At the question "What is your play style?", pick the 2nd answer: "II. Gamer".
   From a cleared save ("Once Again"): pick "Easy".
   On any other difficulty, the seed is not applied.
3. The "Spoiler" tab shows the full list of changes.

UPDATES
The app updates itself: it offers the new version when it starts.

IF SOMETHING GOES WRONG
Open an "issue" on the project's GitHub page, with the file from the "Game log" button
(randomizer_journal.txt), the seed number and the options you ticked.

HELPING THE PROJECT (OPTIONAL)
"Help the project" tab: tick "Survey mode", start a new game and visit rooms without picking
anything up. The items found there are written to the game log.

GETTING THE ORIGINAL GAME BACK
In the app: "Uninstall the DLL". That's all.
