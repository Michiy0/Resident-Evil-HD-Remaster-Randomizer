RANDOMIZER RESIDENT EVIL HD REMASTER — version 0.6.2 (test)
==========================================================

Merci de tester ! Il faut le jeu sur Steam, à jour.

INSTALLER
1. Lance Resident Evil HD Remaster Randomizer.exe.
   Si Windows affiche « Windows a protégé votre ordinateur » : clique
   « Informations complémentaires » puis « Exécuter quand même » (l'exe n'est pas signé).
2. Vérifie que le dossier du jeu est le bon (sinon « Parcourir… »).
   Si un message orange parle de « version non prise en charge », arrête-toi là
   et préviens-moi : ton jeu n'est pas la même version que le mien.
3. Clique « Installer la DLL ».
4. Clique « Générer la seed » (laisse cochée « Installer la seed dans le jeu »).
   Note le numéro de graine affiché.
5. Lance le jeu depuis Steam : NOUVELLE PARTIE, CHRIS, difficulté NORMAL.

QUOI TESTER
- Ramasse des objets (munitions, herbes, rubans encreurs, poignards…) :
  certains doivent être différents de d'habitude.
- Le jeu ne doit ni planter ni ralentir.

ME RENVOYER
- Le fichier ouvert par le bouton « Journal du jeu » (randomizer_journal.txt),
- le numéro de graine et les options cochées,
- ce que tu as remarqué (plantage, objet bizarre, rien de changé…).

AIDER LE PROJET (FACULTATIF)
Dans l'onglet « Aider le projet », coche « Mode relevé », lance une nouvelle partie et visite
les pièces sans rien ramasser (reste 2 secondes dans chacune). Les objets
présents sont notés dans le journal du jeu : envoie-le-moi.

REVENIR AU JEU NORMAL
Dans l'application : « Désinstaller la DLL ». C'est tout.
